# Dagi Agent

Основной режим `/game/` — [агент с шестью навыками](AGENT.md). Старые фильмы и режиссёрская панель удалены.

Для запуска: `uv sync && uv run dagi-web`. Настройка API и авторизации — в корневом [README](../README.md).

Старые физические механизмы и сохранённые проекты поддерживаются сервером для совместимости; новый векторный контроллер не является их мышечным обучением.
