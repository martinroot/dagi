01 / MULTI-SERVER BY DESIGN

One project control plane.
Workers where the work is.

Keep planning, assignment, execution, and verification in distinct layers. Dispatch specialist agents across servers and follow each task through a durable run record.

01 ORCHESTRATE
⌘

Projects become executable plans

Structure goals into roadmaps and bounded assignments. Route each task by role, model, tools, and server instead of treating a project as one giant prompt.

GOAL TREE→ROADMAP→WORKERS
02 DISTRIBUTE
▤

Specialists run across servers

Separate workers by capability and execution boundary. Delegate with explicit context, a shared project budget, and a traceable parent–child run tree.

Research / node-01 Engineering / node-02 Review / node-03
03 OBSERVE
◉

Inspect outcomes, not promises

Stream output and tool events; persist statuses, errors, token usage, cost, and recovery state. Verify deliverables against the task’s acceptance checks.
