01 / ПОДХОД

Контекст не теряется.
Рабочий процесс повторяется.

Dagi превращает хороший запуск в сохранённый сценарий: инструкции, память, навыки и инструменты собраны вокруг агента, а каждая работа живёт в отдельной сессии.

◈

01 — REUSABLE AGENTS

Шаблон — это исполнитель

Задача, system-инструкции, сценарии, skills и разрешённые инструменты сохраняются вместе. Новый запуск получает подготовленный контекст, а не пустой чат.

Изучить библиотеку →

02 — MEMORY

Память с поиском по смыслу

История сессий, сжатые архивы и SQLite FTS5 возвращают важный контекст и проверенный опыт в текущую работу.

SQLite · FTS5 · Retrieval

03 — STREAMING CORE

Видно, что делает агент

Текст приходит потоком. Вызовы инструментов, результаты, ошибки, остановка и восстановление запуска связаны с конкретной сессией.

Python · SSE · Run events
⚒

04 — TOOLING

Инструменты под задачу

Файлы, веб, документы, медиа, SSH и дочерние агенты доступны по конфигурации; чувствительные операции требуют явного подтверждения.

Scoped tools · Approval
◎

05 — PROJECT FLOW

От цели до результата

Цели, roadmap, последовательность задач, исполнители на разных серверах и обратная связь — единый контур управления проектами.

Goals · Roadmap · Workers

06 — INSPECTABLE RUNS

Факты вместо догадок

Run inspector показывает запросы, инструменты, статусы, токены IN/КЕШ/OUT и стоимость по данным провайдера или явно помеченному тарифу.

Usage · Cost · Recovery
