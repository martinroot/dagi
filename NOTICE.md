# Provenance

- The initial prototype published in commit `b14b0ba` adapted code from [Mohamedhasbini/hermes](https://github.com/Mohamedhasbini/hermes) under its MIT license. That snapshot and its license remain in Git history.
- The current implementation is a fresh compact reimplementation informed by the architecture and behavioral invariants of [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) at commit [`848fc0a`](https://github.com/NousResearch/hermes-agent/commit/848fc0ad8be766b9dc10fe42bd80b5fc2d45d95c). No upstream source files are copied into the current `dagi_core/` package.

- The planar running reference is derived from [DeepMimic](https://github.com/xbpeng/DeepMimic), Copyright (c) 2018 Xue Bin Peng, MIT. See [game/THIRD_PARTY_MOTION.txt](game/THIRD_PARTY_MOTION.txt) for the retained license and source files.
